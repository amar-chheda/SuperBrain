Superbrain — Components

FastAPI app, LLM gateway, local models, tokenizers, Postgres and the observability layer

App layers

  • • Clients hit routers; use cases orchestrate via ports
  • • Adapters: Ollama LLM/embedder, httpx/Spider crawlers, chunkers
  • • Middleware binds request_id into every log line

Models + tokenizers

  • • llama3.1:8b, phi3:mini, lfm2.5-thinking:1.2b, nomic-embed-text (768-d)
  • • One priority queue serialises Ollama calls (QA first)
  • • tiktoken cl100k_base and NLTK punkt size and split chunks

Data + observability

  • • One Postgres: pgvector, tsvector FTS, JSONB traces
  • • model_call_logs and query_logs capture every call and gate
  • • Grafana reads them with plain SQL
