Superbrain — User Flow

Ingest and ask paths, the safety gates, and the rows each stage writes for observability

Ingest

  • • URL, text or PDF becomes a job; crawl, dedup, chunk, embed, store
  • • llama3.1:8b chooses the chunking strategy per article
  • • phi3:mini classifies against integer topic IDs

Ask

  • • lfm2.5-thinking:1.2b splits the ask and writes a HyDE passage
  • • Vector + BM25 recall, fused with RRF, judged by phi3:mini
  • • llama3.1:8b answers only from kept evidence, with citations

Fail closed

  • • Weak recall or a failed reranker refuses instead of guessing
  • • Refusals are logged as aborted queries with the reason
  • • Same rows feed the Grafana dashboard
